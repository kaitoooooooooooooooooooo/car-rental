1. Onglet actif - tabIndexProvider (app_shell.dart)

  Garde l'index de l'onglet affiche (0 = Home, 1 = Profile, 2 = Search).

    class TabIndexNotifier extends Notifier<int> {
      @override
      int build() => 0;

      void select(int index) => state = index;
    }

    final tabIndexProvider = NotifierProvider<TabIndexNotifier, int>(() {
      return TabIndexNotifier();
    });

  Changer d'onglet depuis n'importe quel ecran (ex : bouton See all) :

    ref.read(tabIndexProvider.notifier).select(searchTab);


2. Navigation - app_router.dart

  "/" affiche l'AppShell, "/car/:id" la page de detail.

    GoRoute(
      path: '/',
      name: AppRoute.home.name,
      builder: (context, state) => const AppShell(),
      routes: [
        GoRoute(
          path: 'car/:id',
          name: AppRoute.carDetail.name,
          builder: (context, state) {
            final carId = state.pathParameters['id']!;
            return CarDetailScreen(carId: carId);
          },
        ),
      ],
    ),

  Ouvrir le detail d'une voiture :

    context.goNamed(
      AppRoute.carDetail.name,
      pathParameters: {'id': car.id},
    );


3. API - GET /cars/featured (serveur)

  Les 10 voitures les mieux notees.

    exports.getFeaturedCars = (req, res, next) => {
      Car.find()
        .sort({ "note.moyenne": -1, "note.nombre": -1 })
        .limit(10)
        .then((cars) => res.status(200).json(cars))
        .catch(next);
    };

  /featured doit etre AVANT /:id, sinon "featured" est lu comme un id :

    router.get("/", carController.getCars);
    router.get("/featured", carController.getFeaturedCars);
    router.get("/:id", carController.getCarById);


4. Voitures recommandees - RecommendedCarsCard (home_page/)

  Lit le provider et gere les 3 etats avec .when().

    final featuredCarsValue = ref.watch(featuredCarsListFutureProvider);

    return featuredCarsValue.when(
      loading: () => const Center(child: CircularProgressIndicator()),
      error: (error, stackTrace) => Text(error.toString()),
      data: (cars) => ListView.builder(
        shrinkWrap: true,
        physics: const NeverScrollableScrollPhysics(),
        itemCount: cars.length,
        itemBuilder: (context, index) => FeaturedCarCard(...),
      ),
    );
