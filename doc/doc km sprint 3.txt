1. Onglet actif - tabIndexProvider (app_shell.dart)

  Garde l'index de l'onglet affiche (0 = Home, 1 = Profile, 2 = Search).

    class TabIndexNotifier extends Notifier<int> {
      @override
      int build() => 0;

      void select(int index) => state = index;
    }

    final tabIndexProvider = NotifierProvider<TabIndexNotifier, int>(() {
      return TabIndexNotifier();
    });

  Changer d'onglet depuis n'importe quel ecran (ex : bouton See all) :

    ref.read(tabIndexProvider.notifier).select(searchTab);


2. Navigation - app_router.dart

  "/" affiche l'AppShell, "/car/:id" la page de detail.

    GoRoute(
      path: '/',
      name: AppRoute.home.name,
      builder: (context, state) => const AppShell(),
      routes: [
        GoRoute(
          path: 'car/:id',
          name: AppRoute.carDetail.name,
          builder: (context, state) {
            final carId = state.pathParameters['id']!;
            return CarDetailScreen(carId: carId);
          },
        ),
      ],
    ),

  Ouvrir le detail d'une voiture :

    context.goNamed(
      AppRoute.carDetail.name,
      pathParameters: {'id': car.id},
    );


3. API - GET /cars/featured (serveur)

  Les 10 voitures les mieux notees.

    exports.getFeaturedCars = (req, res, next) => {
      Car.find()
        .sort({ "note.moyenne": -1, "note.nombre": -1 })
        .limit(10)
        .then((cars) => res.status(200).json(cars))
        .catch(next);
    };

  /featured doit etre AVANT /:id, sinon "featured" est lu comme un id :

    router.get("/", carController.getCars);
    router.get("/featured", carController.getFeaturedCars);
    router.get("/:id", carController.getCarById);

10. Localisation - GET /cars/:id/location (serveur)

  Les voitures n'ont pas de latitude/longitude. Le serveur envoie
  l'adresse a Google Geocoding et renvoie { lat, lng }.

    const apiKey = process.env.GOOGLE_MAPS_API_KEY;

    const { adresse, codePostal, ville, canton } = car.localisation;
    const address = `${adresse}, ${codePostal} ${ville}, ${canton}, Suisse`;
    const params = new URLSearchParams({ address: address, key: apiKey });

    fetch(`https://maps.googleapis.com/maps/api/geocode/json?${params}`)

  La cle est dans src/server/.env (ignore par git) :

    GOOGLE_MAPS_API_KEY=...

  et chargee au demarrage dans app.js :

    const dotenv = require("dotenv");
    dotenv.config();

  /:id/location doit etre declaree avec les autres routes /:id
  apres /featured, comme pour la route 3.

13. Favoris - FavoritesNotifier (favorites/favorites_provider.dart)

  Meme logique que le projet Pokemon : un Set d'ids, et toggle
  ajoute ou retire l'id.

    class FavoritesNotifier extends Notifier<Set<String>> {
      @override
      Set<String> build() => {};

      void toggle(String carId) {
        if (state.contains(carId)) {
          state = {...state}..remove(carId);
        } else {
          state = {...state, carId};
        }
      }
    }

  FavoriteButton ne se reconstruit que si CETTE voiture change,
  grace a select :

    final isFavorite = ref.watch(
      favoritesProvider.select((favs) => favs.contains(carId)),
    );


14. Voitures en favori - favoriteCarsProvider

  Provider derive : il combine les ids favoris et la liste de
  l'API, et garde seulement les favoris.

    final favoriteCarsProvider = Provider<AsyncValue<List<Car>>>((ref) {
      final favorites = ref.watch(favoritesProvider);
      final carsValue = ref.watch(carsListFutureProvider);
      return carsValue.whenData(
        (cars) => cars.where((car) => favorites.contains(car.id)).toList(),
      );
    });

  FavoriteCarsSection (profile/) l'affiche avec .when() :
  message si la liste est vide, sinon une liste horizontale
  de CarCard qui ouvrent la page de detail.
